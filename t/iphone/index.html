Poki

An open source AI agent that can use your real iPhone for you.

Open Poki by Joseph Zhou and contributors

What it is

Poki lets AI agents operate a real iPhone, the way a person would. It is an independent open source project by Joseph Zhou and contributors. The code is under the AGPL-3.0 license.

What it can do

  • Operates a real iPhone, with no jailbreak and no extra hardware
  • Takes plain-language tasks, like searching in Chrome
  • Accepts tasks through iMessage or Telegram
  • Works as an MCP server for clients like Claude Code and Codex
  • Remembers past tasks and runs repeat tasks faster

What you could use it for

Search and summarize

You could ask Poki to search a topic in Chrome on your iPhone and summarize the top result.

Tasks by message

You could send Poki a request over iMessage and get a progress note back when it is done.

Connect your coding agent

You could connect Poki MCP to Claude Code or Codex so your agent can reach your iPhone.

Repeat jobs faster

You could run the same kind of task again and let Poki use what it remembered from earlier runs.

How to start

  1. Check you have a Mac, an iPhone, a USB data cable and an Apple Account
  2. Get Poki from the GitHub repository (git clone, then run ./bin/setup)
  3. Run npm start and keep it running
  4. Connect your iPhone and tap Trust when asked
  5. Sign in to your model account or add an API key, then send a task

What it costs

Good to know: Poki itself is open source and the page lists no price, but you need your own model account or API key (such as Anthropic, OpenAI or Gemini) and its fees.
